# Masab website

A responsive, single-page healthcare platform website built with Next.js App Router, React, TypeScript, Tailwind CSS 4, and Lucide icons.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`. Use `pnpm build` to create a production build and `pnpm start` to serve it.

## Project structure

- `app/page.tsx` — page sections and illustrative app previews
- `app/components/site-header.tsx` — wordmark and responsive navigation
- `app/globals.css` — brand styles, responsive layouts, and reduced-motion rules
- `app/layout.tsx` — metadata, fonts, and root layout

## Product status

The Masab app is in testing and has not launched. Store buttons are placeholders without download links. Online care, map tracking, ratings, card payments, and care plans are described as upcoming. The phone interfaces on the site are illustrative previews; this website does not provide booking or account features.
